# 百米乐 (Bailemi)

这是百米乐开源音乐平台的前端项目。

**完整项目说明文档请查看根目录的 [README.md](../README.md)**

## 技术栈

- Vue 3 + Vite
- Tailwind CSS
- Pinia 状态管理
- Vue Router
- Axios

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
```

## 项目结构

```
src/
├── components/     # 公共组件
├── views/         # 页面视图
├── stores/       # Pinia 状态管理
├── router/       # 路由配置
└── utils/        # 工具函数
```

## 功能

- ✅ 用户注册/登录
- ✅ 第三方 OAuth 登录（Google、Microsoft、Apple、微信、QQ）
- ✅ 音乐搜索
- ✅ 热门歌曲推荐
- ✅ 个人中心
- ✅ 账号绑定/解绑
- ✅ 修改密码
- ✅ 账号注销
- ✅ 暗色/亮色模式
- ✅ 毛玻璃 UI 设计
